1. WHAT THIS SOFTWARE IS

Remotype Host is the companion program for the Remotype phone app. It runs on
this computer and lets a phone you control act as its keyboard, trackpad and
remote, and — when you turn those features on — show this computer's screen on
your phone or send text and files between the two.

Remotype Host is free of charge and open source. Some features of the Remotype
phone app are paid; the phone app is a separate, closed-source product. This
program is not sold separately.

3. WHAT YOU SHOULD NOT USE IT FOR

This is not a licence restriction — it is a warning worth reading. Remotype Host
injects keyboard and mouse input and can capture the screen of the computer it
runs on. Do not install or use it on a computer you do not own or do not have
permission to control, and do not use it to monitor or control anyone without
their knowledge and consent. Doing so is very likely illegal where you live,
whatever this document says.


4. PERMISSIONS AND PRIVACY

Remotype Host communicates only over your local network or a private network you
have set up yourself. It has no account system and sends no usage data,
analytics or telemetry to Custavia.

Windows may ask you to allow the program through Windows Firewall so your phone
can find this computer. The installer can create those rules for you.

The current privacy policy is published at
https://remotype.custavia.com/privacy and describes how the wider Remotype
product handles data.
